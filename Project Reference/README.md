# 复盘大师 - A 股盘后复盘工具

> Python 本地服务 + 前端静态页面架构（v3.0），零第三方依赖、零成本。服务端代理拉取东方财富真实盘后数据，失败模块明确告警。

## 项目简介

「复盘大师」是一个 A 股每日盘后复盘仪表盘，涵盖市场环境、资金流向、涨跌停统计、情绪分析、主线板块、龙虎榜、两融、热点聚焦等核心模块。适合短线/中线交易者收盘后快速回顾当日盘面、定位主线方向、监控情绪周期。

## 使用方式（本机自用）

1. 双击 **`start.bat`** 启动本地服务器（端口 8000，运行 `server.py`）
2. 浏览器访问 **http://127.0.0.1:8000**（或桌面「复盘大师」快捷方式）
3. 点击右上角 **「🔄 刷新数据」** 拉取当日真实数据
4. 双击 **`stop.bat`** 可停止服务器

> 已配置**开机自启动**：重启电脑后服务器自动运行，直接用桌面快捷方式或收藏夹打开即可。v3.0 起静态资源带 `Cache-Control: no-cache`，浏览器自动加载最新版，**无需再 Ctrl+F5**。

### v3.0 / v3.1 架构升级（✅ 2026-08-21 / 2026-08-22 完成）

- **浏览器直连东财 → Python 服务端代理**：根治浏览器风控限流（v2.2 的一周踩坑源头）

- 静态资源 `Cache-Control: no-cache`，告别手动 `Ctrl+F5`
- **v3.1（2026-08-22）**：
  - 涨停晋级率实时化：新增 `fetch_promotion()` 查昨日+今日涨停池交叉比对，算真实晋级率与涨/平/跌分类（不再硬编码 2026-05-06 演示数据）
  - 涨停原因改用真实行业板块（`hybk`）替代假题材，原因文案标注"待补充"（无免费 API）
  - 修复历史复盘存档日期：从 `meta.fetchedAt` 解析真实交易日写入 `MARKET_DATA.date`，存档/保存按钮不再显示演示日期 `2026-05-07`
  - 数据源模块数 9 → 10，Node E2E 校验 13/13 → 16/16 PASS

## 架构（服务端代理）

```
浏览器 ──fetch──▶ server.py (:8000)
                   ├── 静态文件: index.html / js / css
                   └── /api/market ──▶ data_provider.py
                                        ├── 东财 push2delay / push2ex / datacenter-web
                                        ├── 东财 push2his (K线) ──失败──▶ 腾讯 ifzq ──失败──▶ 磁盘缓存
                                        └── 5 分钟内存缓存（线程安全）
```
